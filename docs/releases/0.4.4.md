# DeckyCache 0.4.4

## Compatibility

**Tested SteamOS: 3.8.28, build 20260922.1 (NVIDIA PC).**

This ZIP includes Open CAS 26.09.0.1102.release modules for exactly:

```text
6.18.50-valve2-1-neptune-618-gc7289a96b14d
```

Supported library sources are ext4 data partitions on separate, non-system drives.
The kernel is not rebuilt or replaced. A different kernel needs a matching bundle.

SSD/NVMe block caching for SteamOS PC using Open CAS. Games stay on the original HDD,
and writethrough keeps game writes and updates on that drive.

- Simple cache-drive format/reuse controls and independent switches for library partitions.
- Persistent cache across clean restarts.
- Cached games with Steam artwork, names and partial cache sizes.
- Small fragments collapsed separately, compact information dialogs and section dividers.
- Clear all cache without formatting the NVMe or deleting games.
- Shutdown ordering for the tested NVIDIA SteamOS setup.
- Illustrated installation and setup guide.

## Install

Download **DeckyCache-0.4.4.zip** from this release.

Enable **Decky Loader settings → General → Developer mode**.
Then open **Developer → Install Plugin from ZIP File → Browse** and select the ZIP,
or paste the attached ZIP's direct download link into **Install Plugin from URL**.
If the link requires signing in, install the downloaded file.

Choose the attached plugin ZIP, not the automatically generated source-code archives.

A selected partition is cached as a whole. No pinning, folder filtering or per-game clear is included.
Game sizes are partial attribution. A clean shutdown is required for cache reuse;
invalid state causes a cold rebuild.

GRID and DiRT 3 ran on the test PC. Normal restart preserved cached data;
GRID produced attributed cache hits and physical NVMe reads after reboot.
Storage-level update coherence was checked on disposable images.
An end-to-end Steam download/update remains unverified.

The plugin runtime matches the tested 0.4.4-dev build; this release changes the version metadata,
packaging and documentation.
