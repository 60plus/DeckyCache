# DeckyCache 0.4.5

DeckyCache adds a master switch and a GitHub updater that selects releases for the running kernel.

## Compatibility

**SteamOS Stable only.** Beta, Preview and Main are not supported.

| Requirement | This release |
| --- | --- |
| Tested SteamOS PC | 3.8.28, build 20260922.1, NVIDIA x86-64 |
| Required kernel | `6.18.50-valve2-1-neptune-618-gc7289a96b14d` |
| Library filesystem | Separate ext4 data partitions |
| Tested Decky Loader | 3.2.10 |

## Changes

- **Enable DeckyCache** turns caching on or bypasses reads to the HDD while retaining valid cached blocks and drive selections.
- Switching OFF and ON keeps cached game entries. Writes while OFF invalidate affected blocks, so Steam updates do not leave stale cached data.
- **Check for updates** finds a newer stable GitHub release with modules for exactly the running kernel.
- The updater verifies the ZIP and bundled modules, then opens Decky's installer. Decky reloads the plugin automatically.
- The panel and updater remain available if no cache module matches the kernel.
- Extra spacing separates the master switch from the update button.

Original games stay on the HDD. There is no kernel rebuild, pinning or full-game copy.

## Install or update

Download the attached **DeckyCache plugin ZIP**, not GitHub's source-code archives.
In Decky settings, enable **General > Developer mode**, then use **Developer > Install Plugin from ZIP File**
or **Install Plugin from URL**.

If the installed version already has the updater, close games and finish Steam downloads, then choose
**Check for updates > Update to 0.4.5** and confirm Decky's installer.
Reopen the plugin and enable caching when ready. Update preparation returns libraries to direct HDD access,
so cache stays off after installation or a cancelled installer and may refill when enabled again.
A normal OFF/ON toggle preserves valid blocks.

The ZIP, `SHA256SUMS` and `deckycache-update.json` are attached. The JSON file lets the plugin verify kernel compatibility.

## Validation

The development build was installed through Decky's native installer without a PC restart.
On the test PC, the OFF/ON switch preserved GRID's 136 MiB of attributed cached data and its mounted library;
the owner confirmed that the game remained listed. GitHub checks succeeded from Decky's embedded Python.
The final runtime matches that build, with only release version metadata changed.

TypeScript typecheck/build and focused updater, recovery and lifecycle checks passed.
An end-to-end Steam game download/update remains unverified; earlier storage checks covered writes and atomic replacement.
