# DeckyCache 0.4.6

The built-in updater now keeps cached data and Steam library mounts connected while Decky replaces the plugin.
This fixes cache rebuilding and installed games disappearing from Steam after a plugin update.

## Compatibility

**SteamOS Stable only.** Beta, Preview and Main are not supported.

| Requirement | This release |
| --- | --- |
| Tested SteamOS PC | 3.8.28, build 20260922.1, NVIDIA x86-64 |
| Required kernel | `6.18.50-valve2-1-neptune-618-gc7289a96b14d` |
| Library filesystem | Separate ext4 data partitions |
| Tested Decky Loader | 3.2.10 |

## Changes

- The storage worker and Open CAS binaries have an independent runtime outside the directory replaced by Decky.
- Compatible updates keep the same mounted cache devices, cached blocks, selected drives and master switch state.
- The worker adopts the new code between operations without stopping the storage service or unmounting libraries.
- Writes continue through Open CAS, so changes to original files remain coherent with cached data.
- Cancelling the installer keeps caching unchanged. If an incomplete installation leaves the plugin absent, the worker returns libraries to direct HDD access after a grace period.
- An update that changes the active cache engine or cannot accept the cache handoff is refused before storage is changed.

## Install or update

Download the attached **DeckyCache plugin ZIP**, not the source-code archive.
Enable Developer mode in Decky settings and install through **Install Plugin from ZIP File** or **Install Plugin from URL**.

For later compatible updates, close games and finish Steam downloads, then use **Check for updates** inside DeckyCache.
Confirm Decky's installer. The plugin reloads automatically and retains your cache switch state.

**Preservation requires the new updater on both sides.** Updating from 0.4.5 or older through its old updater can still rebuild cache once.
Manual ZIP replacement does not use the preservation handoff.
If Steam lost the installed-game list after an earlier update, re-add the existing library in Steam Storage; do not format the HDD or reinstall the games.

## Validation

A native Decky installation from one development build to the next preserved the mounted library and all 31 installed-game entries throughout the operation.
Cache occupancy remained populated, and reading GRID after the update increased cache hits from 2 to 21.
The storage worker adopted the new runtime without a PC restart.

A disposable file on the selected library was written, overwritten and atomically replaced.
Each version matched both the cached filesystem read and a direct read from the original HDD.
This is a storage-coherence check, not an end-to-end Steam game download/update test.

Focused updater/lifecycle checks and TypeScript typecheck/build passed.
