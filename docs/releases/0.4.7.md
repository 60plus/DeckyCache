# DeckyCache 0.4.7

Non-Steam games added to Steam can now appear in **Cached games**, using the names and artwork already set in Steam, including artwork from SteamGridDB.

## Compatibility

**SteamOS Stable only.** Beta, Preview and Main are not supported.

| Requirement | This release |
| --- | --- |
| Tested SteamOS PC | 3.8.28, build 20260922.1, NVIDIA x86-64 |
| Required kernel | `6.18.50-valve2-1-neptune-618-gc7289a96b14d` |
| Library filesystem | Separate ext4 data partitions |
| Tested Decky Loader | 3.2.10 |

The kernel bundle is unchanged from 0.4.6. No kernel rebuild or on-device compilation is required.

## Changes

- Detects non-Steam shortcuts whose executable is inside a selected library partition.
- Uses the shortcut's game folder for Open CAS attribution, alongside regular Steam installations.
- Reuses custom Steam artwork for both Steam games and shortcuts, with alternate image and standard-cover fallbacks.
- Preserves existing cache data, folder tracking and Steam library mounts during a compatible built-in update.

## What appears in Cached games

A shortcut appears only after its folder has attributed cached data. Entries below **16 MiB** are under **Small fragments**.
Simply launching a game does not guarantee a new entry: Linux may serve those reads from RAM.
Previously unclassified data is not counted retroactively; subsequent storage I/O can attribute it without clearing cache.

Tracking remains limited to 32 distinct installation folders per cached volume.
Shortcuts that open an external launcher without exposing the game's executable path are not attributed.
All folders on the selected partition still use the block cache, including data not assigned to a game.

## Install or update

Download the attached **DeckyCache plugin ZIP**, not the source-code archive.
Enable Developer mode in Decky settings and install through **Install Plugin from ZIP File** or **Install Plugin from URL**.

For an existing installation with the current updater, close games and finish Steam downloads, then use **Check for updates** in DeckyCache.
Confirm Decky's installer. The plugin reloads automatically.

Cache preservation requires the compatible built-in updater. Updating through the old updater in 0.4.5 or earlier, or replacing the ZIP manually, can still rebuild cache once.
Original games remain on the HDD.

## Validation

A native Decky update to the development build preserved cache occupancy, all existing tracking IDs and all 31 installed Steam game entries.
Five real non-Steam shortcuts were detected. Blood's existing custom Steam artwork loaded successfully.

A controlled 1 MiB read of a Blood game file was served entirely from NVMe and attributed to Blood, with no original-HDD read.
This was a diagnostic read, not a gameplay benchmark. Existing Steam game-update coherence behavior is unchanged.

Shortcut parsing and path-selection checks, updater/lifecycle checks and TypeScript typecheck/build passed.
